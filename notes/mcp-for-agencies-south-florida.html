Model Context Protocol for agencies: a South Florida primer from Jason Colapietro

Most agencies in West Palm Beach and Jupiter first hear about the Model Context Protocol when a client asks whether their AI assistant can pull the numbers itself. It can, once somebody builds and scopes a server for it, and that somebody is increasingly the agency.

This primer is written by Jason Colapietro, founder of Suede AI, for agency owners and developers in Palm Beach County who need a working understanding of MCP without reading the whole specification first. It uses the Suede MCP server documented on this site as the worked example, because you can call it yourself in under a minute.

What MCP is, in one paragraph

MCP is an open protocol that lets an AI client, such as Claude or a coding assistant, discover and call tools on a server you control. The client sends JSON-RPC messages: initialize to agree on a protocol version, tools/list to learn what the server offers, and tools/call to run one tool with arguments. Each tool carries a name, a description and an input schema, so the model knows what to send. For an agency, that means a client's assistant can reach a defined set of actions instead of copying and pasting between tabs.

A real server you can inspect today

Suede AI runs an MCP server at https://app.suedeai.ai/api/mcp, a streamable-HTTP JSON-RPC endpoint. On 2026-10-11 it answered initialize with protocol version 2025-06-18 and server name suede-agentic-commerce, and tools/list returned five tools. The discovery guide lists each one. You can try a call from any terminal:

curl -s -X POST https://app.suedeai.ai/api/mcp \
  -H 'Content-Type: application/json' \
  -H 'Accept: application/json, text/event-stream' \
  -d '{"jsonrpc":"2.0","id":1,"method":"tools/list"}'

One design choice is worth copying. For the three paid tools, tools/call does not run the job. It returns a payment pointer: the endpoint, the network and the price. The client then pays the HTTP endpoint over x402, as the quickstart shows. MCP describes the work, and money moves over a separate, auditable channel. Suede made that split so a model can never spend funds simply by deciding to call a tool.

Where MCP earns its keep at an agency

  • Reporting. A read-only tool that returns last month's search and analytics figures for one client, so the account lead can ask questions in plain language.
  • Content operations. Tools that draft a page into a staging CMS and stop there, leaving publishing to a person.
  • Site checks. A tool that runs a crawl or schema validation and returns structured findings, the kind of work our technical SEO service does by hand today.
  • Client knowledge. A resource that exposes a client's brand facts, service areas and approved claims, so every assistant session starts from the same truth.

Scoping rules Suede AI uses

  1. Start read-only. Ship tools that look before tools that change anything. Add write access one tool at a time, after the read side has been used for a few weeks.
  2. One server, or one credential set, per client. Never let a tool for one Jupiter client see another client's data because they share a token.
  3. Use one name everywhere. On Suede's stack, create_music, agent_video and agent_image are the catalog ids, the A2A skill ids, the MCP tool names and the OpenAPI operation ids. One name per action makes logs and docs line up.
  4. Return structured content. A JSON object with named fields is easier for the model to use correctly than a paragraph of prose.
  5. Log every call. Record the tool, the arguments and the caller, so a surprising answer can be traced back to the call that produced it.

The tradeoffs

MCP is young and moving. Protocol versions are dated, so a server written against one revision needs attention when clients adopt the next. Authentication is still the part teams spend the most time on, especially for servers that touch client accounts. Not every client supports streamable HTTP yet, and some only run local servers. And every tool you expose is a tool you have to document, test and maintain. An agency that ships ten tools in a week usually ends up retiring seven of them.

Why this matters for South Florida agencies now

Buyers in Palm Beach County already ask assistants which agency to hire, and they will soon expect those assistants to do work on their behalf. Agencies that can design, scope and document an MCP server will be the ones those clients trust with the keys.
