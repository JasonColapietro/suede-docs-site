Suede x402 API endpoints

Three endpoints, one payment rail. Each is a POST to https://app.suedeai.ai, priced per call in USDC on Base, and a paid call returns a job you can poll for free. The figures below come from the live discovery document and OpenAPI spec, checked on 2026-10-11.

amount is the price in USDC base units (6 decimals), exactly as it appears in the 402 challenge and the value you sign. Each endpoint takes a JSON body in which prompt is the only required field.

The same PAYMENT-SIGNATURE header also accepts Skyfire pay+jwt and kya-pay+jwt tokens. The product catalog lists Stripe Checkout as a second payment method at the same USD prices: 50, 499 and 15 cents. The quickstart walks through the x402 payment step by step.

Request headers

HeaderRequiredUse
Content-Type: application/jsonYesAll three endpoints take a JSON body.
PAYMENT-SIGNATUREFor a paid callA base64 x402 PaymentPayload or a Skyfire token. Leave it off the first call to receive the 402 challenge.
X-Idempotency-KeyNoUp to 200 characters. Resending the same key and body within the cache window returns the original response without charging again.
Suede-API-VersionNoPins the API version. The current and only supported value is 1.

Asynchronous by default

A call that carries PAYMENT-SIGNATURE queues the job and answers 202 Accepted with a pollUrl. Renders take minutes, and x402 and Skyfire clients time out in about 30 seconds, so this keeps your payment client from timing out mid-render. Polling needs no further payment.

  • ?async=false forces a blocking call that answers 200 with the finished asset.
  • ?async=true queues the job. Only the literal true selects asynchronous mode; 1, yes and on count as false.
  • The body field asyncMode can switch asynchronous mode on, never off. "asyncMode": false leaves a paid call asynchronous.

All three endpoints answer 202 for a queued job, so a 2xx other than 202 means the asset is already in the body.

Response codes

StatusMeaning
202Paid call accepted and queued. Poll pollUrl.
200Blocking call finished, with the asset in the body.
400Bad request, for example an unsupported Suede-API-Version.
402Payment required, or the payment was not accepted.
422The body failed validation. A paid request that fails validation is not charged.
429Rate-limited. Wait for Retry-After.
5XXServer or upstream failure. Not charged; retry with the same X-Idempotency-Key.

Bodies, headers and retry rules for each code are on the errors page.
