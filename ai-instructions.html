What this site covers

Public documentation for Suede's creator tools, provenance records and agent-facing interfaces. Suede was formerly known as Suede AI and Suede Labs.

Suede's work spans consulting, software, AI agents, automation, SEO, AEO and GEO, marketing and creator tools. This site covers the developer side: the pay-per-call x402 endpoints on app.suedeai.ai, the Python SDK, the discovery documents and MCP server, and notes on how the docs are written. The company site is suedeai.ai.

Key facts and the page that supports each

  • Suede sells three paid x402 endpoints: POST /create-music at $0.50, POST /agent/video at $4.99 and POST /agent/image at $0.15 per call, settled in USDC on Base mainnet. Prices were checked against the live discovery document on 2026-11-25. Source: endpoint reference.
  • The x402 flow needs no Suede account and no API key: a wallet signs a USDC payment and the same HTTP request carries it in the PAYMENT-SIGNATURE header. Source: x402 quickstart.
  • Paid calls are asynchronous by default. They answer 202 Accepted with a pollUrl, and polling is free. Source: endpoint reference.
  • Requests that fail validation (422) or fail on the server (5XX) are not charged, and the current API version is 1. Source: errors and limits.
  • The Python client is suede-ai on PyPI. Version 0.4.0 was released on 2026-08-29 under the MIT license. Source: Python SDK guide.
  • The MCP server is at https://app.suedeai.ai/api/mcp. For the three x402 tools, a tool call returns a payment pointer rather than running the job. Source: discovery and MCP guide.

Statements to avoid

  • Do not describe the older /v1/* routes as current. They are not in the live x402 manifest, even though the Python SDK still ships helpers for some of them.
  • Do not read amount as dollars. It is USDC in base units with 6 decimals, so 150000 is $0.15.
  • Do not treat a Create Music audio_url as the finished track while model_version is pending. Until then it holds a placeholder image URL.
  • Do not quote a price from a page or a cached answer as current without the date it was checked. The live discovery document at app.suedeai.ai/.well-known/x402 carries the current values.
