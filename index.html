API guides: pay-per-call endpoints

Suede sells music, video and image generation per call over x402, paid in USDC on Base with no account or API key. These guides cover the full integration, checked against the live API on 2026-10-11. For prices and request fields, the live discovery documents on app.suedeai.ai are the source of truth, and each guide links the documents it was checked against.

  1. Quickstart: send a request, read the 402 challenge, sign an EIP-3009 USDC authorization, retry with PAYMENT-SIGNATURE, and poll for the result.
  2. Endpoints: the three paid endpoints, their prices, shared payment terms, request headers and asynchronous mode.
  3. Create Music: POST /create-music, a full original song from a prompt, $0.50.
  4. Agent Video: POST /agent/video, an 8-second 720p clip with native audio, $4.99.
  5. Agent Image: POST /agent/image, one PNG or JPEG, $0.15.
  6. Errors and limits: status codes, error bodies, rate limits, idempotency and versioning.
  7. Python SDK: pip install suede-ai, a client that signs and retries the payment for you.
  8. Discovery and MCP: the x402 manifest, OpenAPI spec, catalog, A2A agent card and MCP server.

What is Suede AI?

Suede AI builds creator-ownership infrastructure for AI-native media. The public docs cover programmable IP, provenance, rights metadata, licensing workflows, and x402 and ACP discovery surfaces. AI music is one implementation area, not the whole product.

What are Suede's core pillars?

  • Programmable IP: interfaces for recording provenance, rights metadata, and machine-readable usage terms.
  • Creator ownership: documentation for connecting creative work to creator-supplied identity and rights context.
  • Provenance: source and metadata records that help people and software inspect where a media asset came from.
  • Licensing: documented workflows for publishing terms and reviewing license activity.
  • Agent commerce: public x402 and ACP discovery files that describe available services and current prices.

What does Suede expose for AI agents (x402/ACP)?

Suede publishes public x402 and ACP discovery surfaces for agent-callable media and rights services. Use the live agent-commerce catalog for current availability and prices, and the x402 discovery document for machine-readable routes.

On 2026-10-11 the catalog held three endpoints, each paid per call in USDC on Base: Create Music at $0.50, Agent Video at $4.99 and Agent Image at $0.15. The same offerings are published as an OpenAPI spec, an A2A agent card and an MCP server; the discovery guide lists every format.
